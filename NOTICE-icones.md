# Icônes

Certaines icônes de Sillage viennent de la collection **Fluent Color** de Microsoft (https://github.com/microsoft/fluentui-system-icons), distribuée sous licence MIT, consultée via https://icon-sets.iconify.design/fluent-color/.

Copyright (c) 2020 Microsoft Corporation. Licence MIT : https://github.com/microsoft/fluentui-system-icons/blob/main/LICENSE

Les dessins sont convertis en `VectorDrawable` (`app/src/main/res/drawable/` : couleurs unies ; `drawable-v24/` : dégradés, Android 7+).

Icônes concernées : `ic_settings`, `ic_warning`, `ic_error`, `ic_folder`, `ic_edit`, `ic_search`, `ic_favorite_filled`, `ic_headphones`, `ic_palette`, `ic_groups`, `ic_schedule`, `ic_alarm_on`, `ic_article`, `ic_manufacturing`, `ic_playlist_play`, `ic_collections_bookmark`, `ic_share_24`, `ic_refresh`, `ic_equalizer`, `ic_dashboard_customize`, `ic_text_fields`, `ic_genres`.

Retour en arrière : `git revert` du commit « Icônes Fluent Color » rend les icônes Material d'origine.
