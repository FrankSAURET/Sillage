# Sillage
Application lecteur de musique android et car

Sillage est un lecteur de musique Android libre et hors ligne, dérivé de [Gramophone](https://github.com/FoedusProgramme/Gramophone). Il est publié sous licence GPL-3.0, comme son origine (voir `LICENSE`).

- Cahier des charges, choix techniques et feuille de route : [SILLAGE.md](SILLAGE.md)
- README d'origine de Gramophone : https://github.com/FoedusProgramme/Gramophone

Après un clonage, récupérer les sous-modules avant de compiler :

```
git submodule update --init --recursive
```
